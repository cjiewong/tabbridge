# Code of conduct

Everyone participating in issues, pull requests and project discussions is expected to:

- Treat contributors respectfully and critique ideas or code rather than people.
- Accept constructive feedback and make space for different experience levels and backgrounds.
- Keep discussion relevant, factual and accessible.
- Protect other people's privacy; do not post personal data, credentials or private screenshots.

Harassment, threats, discriminatory remarks, sexualized content, doxxing and repeated unwanted contact are not acceptable. These rules also apply when someone represents the project elsewhere.

## Reporting and moderation

Use GitHub's **Report content** or **Report abuse** controls for a confidential report to GitHub. To request repository moderation, open an issue linking the public interaction, without repeating abusive material or personal information. If confidential follow-up with a maintainer is needed, request a private contact channel without posting incident details. The project does not currently operate a separate conduct-reporting inbox.

Maintainers may edit or remove inappropriate content, close discussions or restrict participation. Responses should be proportionate to the behavior and its impact. Apply the same standards to maintainers and contributors. Do not retaliate against someone for making a good-faith report.
